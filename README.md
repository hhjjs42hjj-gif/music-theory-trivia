# Music Theory Trivia
A trivia game for learning and practicing music theory. 

## Overview
This game allows users to interact with musical notes on a staff and answer questions about music theory.

## Compositions

### Ethereal Whispers
A delicate and fragile piece for strings and woodwinds, designed to create an expressive, ethereal, and tender mood.

**File:** [`compositions/ethereal_whispers.ly`](compositions/ethereal_whispers.ly)

**Instrumentation:**
- **Woodwinds:** Flute, Oboe, Clarinet in B♭, Bassoon
- **Strings:** Violin I, Violin II, Viola, Violoncello

**Musical Characteristics:**
- **Tempo:** Adagio, con delicatezza (♩ = 56)
- **Key:** D Major
- **Time Signature:** 4/4
- **Character:** Ethereal, tender, and expressive

**Scoring Practices:**
- **Dynamics:** Primarily pp to mp for delicate, fragile character
- **Articulations:** Legato phrasing with espressivo markings
- **Instrumental Ranges:** All parts stay within standard comfortable ranges
  - Flute: Middle to upper register for ethereal quality
  - Oboe: Warm expressive middle register
  - Clarinet: Warm chalumeau and clarion registers
  - Bassoon: Gentle bass foundation
  - Strings: Lyrical melodic lines with supporting harmonies

**How to Render:**
This composition is written in [LilyPond](https://lilypond.org/) notation format. To generate sheet music:
```bash
lilypond compositions/ethereal_whispers.ly
```
This will produce PDF and MIDI files.
